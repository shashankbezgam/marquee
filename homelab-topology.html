Storage — one filesystem, hardlink-ready

TRaSH layout · instant moves + hardlinks
/data                       # single mount, single fs
├── torrents            ← qbittorrent (rw, this only)
│   ├── movies · tv · music …
│   └── torrents-files/      # .torrent files
├── usenet              # reserved (sabnzbd off)
│   ├── incomplete/  └─ complete/
└── media               ← plex (ro)
    └── movies · tv · music · books · photos · other

Read-only library; can't mutate sources. ✓

07

State of the build

✓ Edge/backend split is now clean

gluetun is off the edge, qui is correctly dual-homed, tautulli is edge-only. The doorman's plane holds only what it serves.

✓ VPN segmentation + secrets

qbit/prowlarr/flaresolverr ride gluetun with a kill-switch. Credentials live in per-stack .env files, out of the compose.

✓ Storage is textbook

Single /data filesystem, *arr mount the whole tree → hardlinks and instant moves. Plex on :ro.

⚠ Treat dockge as root

dockge mounts /var/run/docker.sock and sits on the LAN. Whoever reaches its UI effectively controls the host — keep it strongly authed.

◷ When cloudflared lands

Point the public tunnel only at light HTML apps (seerr). Don't stream Plex through the free Cloudflare tunnel — it's against their ToS.

✓ Hostname-based, no static IPs

Docker DNS resolves containers by name on whichever shared net — unambiguous and restart-proof.
